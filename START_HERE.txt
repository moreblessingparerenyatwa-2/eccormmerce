  ⚡ QUICK START (3 MINUTES)
═══════════════════════════════════════════════════════════════

STEP 1: Open Command Prompt
────────────────────────────
Press Windows Key + R, type "cmd", press Enter

STEP 2: Navigate to Project
────────────────────────────
cd "c:\Users\UncommonStudent\Desktop\django eccormmerce"

STEP 3: Run Setup (Choose One)
──────────────────────────────

Option A - AUTOMATIC (Recommended):
   setup.bat
   
Option B - MANUAL:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python manage.py migrate

STEP 4: Create Admin Account
─────────────────────────────
python manage.py createsuperuser
(Follow prompts: enter username, email, password)

STEP 5: Add Sample Products
────────────────────────────
python populate_sample_data.py

STEP 6: Start Server
────────────────────
python manage.py runserver

STEP 7: Open in Browser
───────────────────────
Go to: http://127.0.0.1:8000/

═══════════════════════════════════════════════════════════════
  🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Port 8000 already in use
Solution: python manage.py runserver 8001

Problem: Module not found
Solution: pip install -r requirements.txt

Problem: Static files not showing
Solution: python manage.py collectstatic --clear

Problem: Database error
Solution: Delete db.sqlite3, then: python manage.py migrate
